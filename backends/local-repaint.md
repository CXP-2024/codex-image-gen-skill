# 局部重绘修细节(`eye_fix.py`)

> **2026-10-22 起修眼睛默认用 `codex_eye_edit.py`**(Codex 编辑 + 只贴回虹膜,用户比较了 Codex / Qwen Image 2.1 / K2 General Edit 后选定)。job 格式见脚本开头;每张会写出 `<out>_eyecheck.png`(原图 / Codex / 贴回),逐只眼放大检查,有旧虹膜残留就给那只眼加 `"add"` 多边形再跑一次(Codex 结果已缓存)。
> - 量眼睛:中心和半径大致准即可,贴回区域由 `eye_fix.iris_region` 按原图虹膜轮廓自动拟合;小眼睛(r < 20)和半闭的眼睛拟合常偏,要看检查图。
> - 实测(cinema10 的 02 电车、05 化妆镜):四只眼一次成功,只有两只边缘残留旧颜色,加 `add` 后干净。
> - 小人物整体崩坏(07 玫瑰窗,人物头部约 60px)用 `region_redraw.py` 放大重绘,不是修眼睛。

出图后发现小细节画错(实测:芙宁娜的异色水滴瞳 K2 画不出来),不重出整张,只把那一块重画。工具是本目录的 `eye_fix.py`,目前针对眼睛,方法对任何小区域都适用。2026-10-21 在芙宁娜三张图上验证过,用户认可。

## 原理

AI 部分(K2 局部重绘,所有扩散模型都有这个能力):

1. **裁下来放大**:眼睛在原图只有 60–120px,以虹膜中心裁出边长 `r × 2.4 × 2` 的方块,放大到 768×768,模型才有像素画细节。
2. **椭圆遮罩**:只盖住虹膜(半径 = `r`,纵向 ×1.1)。盖到眼睑/睫毛会糊。
3. **低噪点重绘**:原图编码后加约 60% 噪点(`denoise` 0.62)再去噪,模型能看到周围原有的线条和颜色,画出来的东西会和周围衔接。K2 + `kieed_v1_epoch20` 0.6 保持画风,10 步,CFG 1。
4. **一只眼一只眼画**:每只眼的提示词只写这一只眼。两只眼写在同一段里模型会把左右属性弄混。
4.5 **草图引导**(默认):重绘前先在虹膜位置画好官方设计的彩色草图,再低强度重绘,形状颜色就能精确(见下文)。
5. **多抽几次**:每只眼跑 3 个 seed,挑形状最像的。

非 AI 部分(贴回时的规则,模型本身不懂遮挡):

6. **羽化融合**:遮罩高斯模糊后缩回原尺寸贴回,看不出接缝。
7. **保留头发**(`keep_hair`,默认开):找出原图里"浅色、低饱和、并且从遮罩外伸进来"的像素连通块,当作头发留在新眼睛前面。眼睛里原来的高光是孤立小点,不会被保留。
7.5 **保留眼睑和睫毛**(`keep_lids`,默认开):动漫虹膜的上缘通常压在上眼睑下面。原图里从遮罩外伸进来的深色线条(睫毛、眼睑线、虹膜外轮廓)在虹膜**外圈 0.35 r 以内**的部分会留在新眼睛前面;更靠里的(比如旧瞳孔的描边)照常重画,不会残留。
8. **还原遮挡物**(`restore`):眼镜镜片这类有颜色的遮挡会被第 7 步误判,要关掉 `keep_hair`,改用 `restore` 按颜色 + 一条分界线把遮挡物从原图取回来叠在最上面。

## 用法

```json
{"image": "H:\\...\\in.png", "out": "H:\\...\\out.png", "seed": 11, "denoise": 0.62,
 "eyes": [{"cx": 595, "cy": 580, "r": 38, "kind": "light"},
          {"cx": 785, "cy": 621, "r": 29, "kind": "dark"}]}
```

```powershell
H:\MiniMaxH3\.venv\Scripts\python.exe <skill目录>\eye_fix.py --job job.json
```

- 需要 ComfyUI(8288)在跑;用 `H:\MiniMaxH3\.venv` 的 Python(要 numpy、scipy、PIL)。
- `cx, cy` 是虹膜中心,`r` 是**水平**半径,`ry` 是竖直半径(不填默认 1.1 r),单位都是原图像素。
- **必须量准,而且要验证**(2026-10-22 用户放大发现的问题):在**原图**上把眼睛周围裁出来放大 3–4 倍、画 10px 网格,沿虹膜的深色外轮廓量左右和上下边缘;然后把椭圆画在原图上叠加检查,椭圆必须压在原轮廓上。量偏了(哪怕 10px)原来的外圈会露出来变成"双层眼眶",量小了旧虹膜会残留。动漫虹膜常常比高宽,别默认是圆。
- `kind`:`light` / `dark` 是芙宁娜的两只眼(见下);别的角色写 `"prompt": "..."`,只描述这一只眼。
- 每只眼跑 3 个 seed(11 / 22 / 33),出一张"原图 + 三个版本"的眼部特写拼图,挑完再给用户看完整图。

### 芙宁娜的眼睛(官方角色卡立绘,2026-10-22 放大核对)

左右按**她自己的**左右眼定,不按画面:正对观众时她的右眼在画面左边;侧身、背影回头、镜像构图要先判断是哪只眼。

| 她的哪只眼 | `kind` | 设计 |
|---|---|---|
| 右眼(正面时在画面左) | `light` | 浅天蓝/浅青虹膜,细放射纹,深海军蓝外圈;**深紫蓝、细长**的水滴瞳,尖头朝上,**位置偏上**、贴近虹膜上缘;虹膜底部一块白色高光 |
| 左眼(正面时在画面右) | `dark` | 深紫蓝虹膜,**下缘一道粉紫色边**,深色外圈;**浅青、细长**的水滴瞳,尖头朝上,偏上;几道细小白色反光 |

只露出一只眼的构图(如磁带遮眼)只修露出的那只。

### 草图引导(默认开,用户认可的精确还原法)

`kind` 为 `light` / `dark` 时,脚本先在放大的裁图上**用程序画出官方设计的彩色草图**(渐变虹膜、外圈、细长水滴瞳、放射纹/粉紫边、高光,`draw_guide()`),再用低强度(`guide_denoise`,默认 0.45)重绘。形状和颜色由草图决定,模型只负责把它画成 kieed 的笔触。

- 实测强度:0.35 偏"贴图感",0.45 最好,0.55 开始自由发挥、形状变形。
- 头部明显倾斜时给这只眼加 `"angle": 角度`(逆时针为正),让水滴跟着头的方向。
- `"debug_dir": "某文件夹"` 会保存草图,方便检查位置。
- 关掉草图:`"guide": false`(回到纯提示词重绘,形状不受控)。

### 戴眼镜 / 有遮挡物

`"keep_hair": false`,再加 `restore`。`source` 填重绘前的原图(没有修过任何一只眼的那张),`color` 用取色得到的遮挡物颜色,`above` 是遮挡物下边缘上的两点(原图坐标),只还原这条线以上的部分:

```json
{"image": "...\\left_eye_done.png", "out": "...\\out.png", "seed": 55, "keep_hair": false,
 "eyes": [{"cx": 965, "cy": 704, "r": 67, "ry": 62, "kind": "dark"}],
 "restore": [{"source": "H:\\...\\original.png", "box": [870, 600, 1060, 800],
              "color": [201, 237, 236], "tol": 38, "above": [[870, 653.2], [1060, 720.6]]}]}
```

## 局限

- 每张新图都要量坐标、跑一遍,约 1–2 分钟/张。
- 草图引导后形状基本固定,但不同 seed 的笔触和高光仍有差异,建议跑 2 个 seed 挑。
- 遮挡关系靠规则补,复杂遮挡(半透明发丝、手挡眼睛)可能处理不好。那种情况用真正的图像编辑模型更合适(Qwen-Image Edit,本地未下载;或 Codex 编辑,耗额度)。
- 根治办法是训练芙宁娜的 K2 角色 LoRA。
